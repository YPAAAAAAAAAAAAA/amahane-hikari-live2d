# Amahane-Hikari-Live2D

A clean-room, from-scratch re-implementation of the idea behind **[luomo66ccff/amahane-hikari-live2d](https://github.com/luomo66ccff/amahane-hikari-live2d)** by [@luomo66ccff](https://github.com/luomo66ccff). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
